# Test results

One markdown file per release tag, for example `ios-v1.0-build1.md`, with:

1. The header from the manual run (date, version / build, device, iOS version) and its summary counts.
2. A **Unit tests** section: the Xcode test summary (total, passed, failed) and any failing test names.
3. The full manual results table copied from the QA page.

Files are added after a run and not edited afterwards.
